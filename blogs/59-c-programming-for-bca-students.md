# C Programming for BCA Students: From Basics to Projects

C is the foundation language of computer science. Learning it well gives you a mental model of how computers work that makes every other language easier to learn. Here's the complete guide for BCA students.

---

## Why C First?

- Most BCA/B.Tech universities use C in first semester
- Understanding memory, pointers, and manual memory management gives you insight no higher-level language provides
- Data structures in C teach you what the language does behind the scenes
- Many competitive coding problems are best approached with C knowledge

---

## C Programming Syllabus (BCA/B.Tech First Year)

### Unit 1: Basics
- Introduction to programming, compilers, and IDEs
- Variables, data types (`int`, `float`, `char`, `double`)
- Input/Output (`printf`, `scanf`)
- Operators (arithmetic, relational, logical, bitwise)
- Type conversion and casting

### Unit 2: Control Flow
- Conditional statements (`if`, `else if`, `switch`)
- Loops (`for`, `while`, `do-while`)
- `break`, `continue`, `goto` (know but avoid `goto`)

### Unit 3: Functions
- Function declaration, definition, calling
- Pass by value vs pass by reference
- Recursion (factorial, Fibonacci, Tower of Hanoi)
- Storage classes (`auto`, `static`, `register`, `extern`)

### Unit 4: Arrays and Strings
- 1D and 2D arrays
- String functions (`strlen`, `strcpy`, `strcmp`, `strcat`)
- Character arrays vs string literals

### Unit 5: Pointers (The Most Important Topic)
- What is a pointer? `int *p = &x;`
- Pointer arithmetic
- Pointers and arrays
- Pointers to functions
- Double pointers `**p`

### Unit 6: Structures and Unions
- Defining and using structures
- Nested structures
- Structure with pointers
- Unions and their use cases

### Unit 7: File Handling
- `fopen`, `fclose`, `fread`, `fwrite`, `fprintf`, `fscanf`
- Sequential vs random file access

### Unit 8: Data Structures in C
- Linked lists (singly, doubly)
- Stacks and queues using arrays and linked lists
- Binary trees (optional at BCA level)

---

## Practice Projects for BCA C Students

1. **Student grade calculator** — arrays + functions
2. **Library management system** — structures + file handling
3. **Simple calculator** — functions + switch
4. **Matrix operations** — 2D arrays + pointers
5. **Linked list implementation** — pointers + dynamic memory

---

## Common Exam Questions in C (University Level)

- Write a program to reverse a string without using library functions
- Implement a stack using an array with push/pop operations
- Write a recursive function for binary search
- Find the largest element in an array using pointers
- Implement a singly linked list with insert, delete, and display
