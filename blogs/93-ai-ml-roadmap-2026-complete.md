# Complete AI ML Roadmap for 2026 — From Zero to Job-Ready

The most common question Satyaki Das receives: "How do I start learning AI/ML?" Here's the definitive 12-month roadmap for 2026.

## Prerequisites Check

Before starting, honestly assess:
- [ ] Can I write a basic Python program?
- [ ] Do I understand basic algebra (variables, equations)?
- [ ] Am I okay spending 2–3 hours/day learning?

If Python is zero: add 1 month for Python basics at the start. Everything else follows.

## Phase 1: Foundations (Month 1-2)

### Python for Data Science
- Variables, loops, functions, OOP
- NumPy: numerical operations, array manipulation
- Pandas: data frames, data cleaning, groupby operations
- Matplotlib + Seaborn: data visualization

**Resources:**
- Python.org official tutorial
- Kaggle's free Python course
- Practice: 1 mini-project per week

### Mathematics for ML
- **Linear Algebra**: vectors, matrices, matrix multiplication
- **Statistics**: mean, median, standard deviation, distributions
- **Probability**: Bayes theorem, conditional probability
- **Calculus**: derivatives (concept-level understanding)

**Resources:**
- 3Blue1Brown (YouTube): "Essence of Linear Algebra"
- Khan Academy Statistics (free)

---

## Phase 2: Core Machine Learning (Month 3-4)

### Supervised Learning
- Linear Regression (house price prediction)
- Logistic Regression (spam detection)
- Decision Trees + Random Forest
- Support Vector Machines (SVM)
- k-Nearest Neighbors (kNN)

### Unsupervised Learning
- K-Means Clustering
- Principal Component Analysis (PCA)
- Hierarchical Clustering

### Model Evaluation
- Train/test split, cross-validation
- Accuracy, Precision, Recall, F1, AUC-ROC
- Overfitting vs underfitting

**Tool**: scikit-learn (Python)  
**Practice**: 2 complete projects (one classification, one regression)

---

## Phase 3: Deep Learning (Month 5-6)

### Neural Network Basics
- What is a neuron, layer, activation function
- Forward propagation, backpropagation
- Gradient descent, learning rate

### Deep Learning Frameworks
- **PyTorch** (recommended) OR TensorFlow/Keras
- Build a neural network from scratch
- Build a CNN (image classifier)
- Build an RNN (sequence data)

**Project ideas:**
- Image classifier (CIFAR-10 dataset)
- Text sentiment classifier

---

## Phase 4: Specialization (Month 7-8)

Choose ONE area to go deep:

**A. NLP + LLMs**
- Transformers, BERT, GPT
- Hugging Face ecosystem
- LangChain + RAG applications

**B. Computer Vision**
- YOLO for object detection
- Image segmentation (SAM)
- Real-time applications with OpenCV

**C. Data Engineering (for Data Engineer path)**
- Apache Spark, Kafka
- Cloud data pipelines (AWS/GCP)
- SQL analytics

---

## Phase 5: MLOps + Deployment (Month 9-10)

This is where most learners stop — don't stop here.

- **Model serving**: Flask/FastAPI REST APIs
- **Containerization**: Docker
- **Cloud deployment**: AWS SageMaker, GCP Vertex AI, Azure ML
- **Monitoring**: MLflow for experiment tracking
- **CI/CD for ML**: GitHub Actions + automated retraining

**Project**: Deploy an end-to-end ML pipeline to the cloud.

---

## Phase 6: Portfolio + Job Search (Month 11-12)

### Build Your Portfolio
- 3–5 GitHub projects (complete, well-documented)
- 1 Kaggle competition submission
- Personal blog or LinkedIn posts about your learning

### Job Search
- Update LinkedIn with AI/ML skills
- Apply to data analyst, ML engineer, and AI engineer roles
- Practice DSA for technical interviews
- Mock interviews (Pramp, interviewing.io)
