# How to Get Placed at TCS, Wipro, Infosys, Accenture as a Fresher in 2026

Service companies like TCS, Wipro, Infosys, and Accenture hire tens of thousands of freshers every year. The process is structured and predictable — meaning it's very preparable. Here's exactly what to do.

---

## Understanding the Hiring Process

All four companies follow a broadly similar process:

1. **Resume screening** — CGPA, degree, communication
2. **Online Assessment (OA)** — Aptitude + Coding + Verbal/Logical
3. **Technical Interview** — CS fundamentals + coding
4. **HR Interview** — motivation, communication, fit

---

## TCS NQT Pattern (2026)

TCS hires through the National Qualifier Test (NQT):

| Section | Topics | Duration |
|---|---|---|
| Aptitude | Quant, logical, verbal | 90 min |
| Programming Logic | Pseudocode, flowcharts | 30 min |
| Coding | 1–2 problems in C/Java/Python | 45 min |

**Scoring:** Higher NQT scores unlock higher-paying tracks (TCS Digital, TCS BPS).

---

## Infosys InfyTQ / Hiring Pattern
- Aptitude (logical + verbal + mathematical)
- Coding test (2 problems, easy–medium)
- Technical HR interview
- Focus areas: Java, Python, SQL basics, OOPs

---

## Wipro Elite / NLTH Pattern
- Aptitude
- Essay writing
- Coding (2 problems)
- Technical interview focusing on CS fundamentals

---

## Accenture Assessment
- Aptitude + Communication test
- Coding test
- Group discussion (some batches)
- Technical + HR interview

---

## 6-Month Preparation Plan

### Months 1–2: Aptitude Foundation
- Quantitative aptitude (time-speed-distance, percentages, averages, profit-loss)
- Logical reasoning (syllogisms, series, coding-decoding)
- Verbal (reading comprehension, grammar)
- Resource: IndiaBix, RS Aggarwal

### Month 3–4: Technical Foundation
- C / Java / Python — know at least one well
- OOPs concepts (classes, inheritance, polymorphism)
- DBMS basics (SQL queries, normalization)
- OS basics (process management, memory)
- CN basics (OSI model, TCP/IP)

### Month 4–5: Coding
- Arrays, strings, searching, sorting
- Basic dynamic programming
- Easy–medium LeetCode problems (100+)

### Month 6: Mock Interviews + Final Prep
- Full-length mock tests (timed)
- Mock interviews with feedback
- HR preparation (tell me about yourself, strengths, career goals)
