## Python Learning Path for WB Students

### Phase 1: University-Aligned Basics (1–2 months)
Covers what MAKAUT, Calcutta University, and most WB university exams test:
- Variables, data types, control flow, functions
- Lists, tuples, dictionaries, sets
- File handling, exception handling
- OOPs in Python

### Phase 2: Data Science Extension (2–3 months)
Beyond the university curriculum — what industry expects:
- NumPy and Pandas
- Data cleaning and visualization (Matplotlib, Seaborn)
- SQL integration with Python
- Project: Analyze a real WB economic dataset

### Phase 3: AI and ML (3–6 months)
- scikit-learn for classical ML
- TensorFlow or PyTorch basics
- LLM API integration (OpenAI, Anthropic)
- Project: Build an AI-powered application
