# Resume Building for BCA/B.Tech Freshers: Complete Guide 2026

Your resume gets 6 seconds of attention before a recruiter decides to read further or move on. For freshers, it's even more competitive — hundreds of applications for the same role. Here's how to stand out.

---

## The Structure That Works in India (2026)

Keep your resume to **1 page** for freshers. Use this order:

1. **Name + Contact** (name, email, phone, LinkedIn, GitHub)
2. **Objective/Summary** (2 lines max — specific, not generic)
3. **Education** (most recent first, include CGPA if 7.5+)
4. **Technical Skills** (organized by category)
5. **Projects** (2–3 real projects — this is the most important section)
6. **Experience** (internships, part-time, freelance — if any)
7. **Achievements** (coding contest ranks, certifications, hackathons)
8. **Extracurriculars** (optional, only if impressive)

---

## The Projects Section: Where Most Freshers Fail

This is your most important section. Don't just name the project — describe it with impact:

**Weak:** "E-commerce website using Java and MySQL"

**Strong:** "Full Stack E-Commerce Platform | Java Spring Boot + React.js + MySQL  
Built a multi-user e-commerce platform with user authentication, product search, cart management, and order tracking. Deployed on AWS EC2. 50+ active test users."

For every project, include:
- Technology stack
- What problem it solves
- One metric (users, performance improvement, data processed)
- GitHub link or live URL

---

## Technical Skills: What to Include

Organize by category:
- **Languages:** Java, Python, C, JavaScript
- **Frameworks:** Spring Boot, React.js, Django
- **Databases:** MySQL, MongoDB, PostgreSQL
- **Tools:** Git, Docker, Postman, IntelliJ
- **Concepts:** OOPs, DSA, REST APIs, Agile

Only list skills you can answer interview questions about. Listing "Machine Learning" when you've only watched 2 YouTube videos will backfire.

---

## Common Fresher Resume Mistakes

❌ Photo on resume (not needed for tech roles at most companies)  
❌ Objective: "To work in a dynamic environment..." (generic = rejected)  
❌ Only listing college projects without live links  
❌ Mentioning every technology ever touched  
❌ Poor formatting (multiple fonts, inconsistent spacing)  
❌ Missing GitHub link  
❌ Spelling and grammar errors (auto-rejection at most companies)

---

## ATS (Applicant Tracking System) Tips

Most companies use ATS to filter resumes before a human sees them:
- Use standard section headers (Education, Experience, Projects, Skills)
- Avoid tables, columns, and graphics (ATS can't parse them)
- Include keywords from the job description
- Use a clean, single-column format
- Save as PDF (not Word .docx)
