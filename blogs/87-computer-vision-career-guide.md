# Computer Vision Career Guide for Indian Students 2026

Cameras are everywhere. From CCTV to self-driving cars to medical imaging — computer vision is the AI skill that lets machines see. Here's your complete guide.

## What Is Computer Vision?

Computer Vision (CV) is a field of AI that enables machines to interpret and understand visual information from images and videos.

CV is used in:
- **Face recognition** (phone unlocking, security systems)
- **Medical imaging** (detecting tumors in X-rays)
- **Autonomous vehicles** (seeing the road)
- **Quality control** (defect detection in manufacturing)
- **Retail** (cashierless stores like Amazon Go)
- **Agriculture** (crop disease detection)

## Key Tools and Frameworks

| Tool | Purpose |
|------|---------|
| OpenCV | Classical CV operations (edge detection, filters) |
| PyTorch | Deep learning models for vision |
| TensorFlow + Keras | Alternative to PyTorch |
| YOLO (v8, v9) | Real-time object detection |
| Hugging Face | Pre-trained vision models |
| Detectron2 (Meta) | Object detection/segmentation |
| NVIDIA CUDA | GPU acceleration for training |

## Learning Roadmap

**Month 1: Foundations**
- Python + NumPy (image as arrays)
- OpenCV: reading images, color spaces, filters, edge detection
- Basic ML: understand CNN conceptually

**Month 2: Deep Learning for Vision**
- PyTorch CNN: build from scratch
- Transfer learning: use ResNet, VGG, EfficientNet
- Fine-tune on custom dataset

**Month 3: Advanced CV**
- Object detection with YOLO
- Image segmentation (U-Net, SAM from Meta)
- Face detection and recognition

**Month 4: Projects + Deployment**
- Build a complete CV application
- Deploy with Flask/FastAPI + OpenCV
- Real-time webcam inference
