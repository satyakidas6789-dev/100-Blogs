# Skills vs Degree for Software Jobs: What Actually Gets You Hired?

Every year, thousands of BCA, B.Tech, and MCA graduates send out hundreds of applications and hear nothing back. Meanwhile, some students from average colleges land ₹12–18 LPA roles. What separates them?

It is not the degree. It is the skills.

---

## What Hiring Actually Looks Like

Most Indian tech companies (and increasingly global ones) hire through a multi-stage process:

1. **Resume shortlist** — degree + CGPA filters (this is where degree matters)
2. **Online assessment** — DSA, aptitude, or coding test (skills matter here)
3. **Technical interview** — DSA problems, system design, project discussion (100% skills)
4. **HR round** — communication, culture fit, career goals

The degree gets you past Stage 1. Everything after that is skills.

---

## What the Interview Actually Tests

### Product Companies (FAANG, Startups)
- DSA: Arrays, trees, graphs, dynamic programming
- System design (for 2+ years experience)
- Problem-solving speed and thought process

### Service Companies (TCS, Infosys, Wipro, Accenture)
- Aptitude and reasoning
- Basic programming knowledge (Java, Python, C++)
- Communication skills
- Domain knowledge (for lateral hiring)

### Startups
- Real project portfolio
- GitHub activity
- Specific tech stack knowledge (React, Node, Django, etc.)
