## The Core Programs at code.classroomtech.in

### 1. Java Full Stack Development
**Who it's for:** BCA, B.Tech, MCA students + working professionals  
**What you learn:** Core Java → OOPs → Collections → Spring Boot → REST APIs → React.js → MySQL → Deployment  
**Outcome:** Job-ready as a Java Full Stack developer at TCS, Infosys, Wipro, and similar companies

### 2. Python + AI/ML Track
**Who it's for:** Students and professionals wanting to enter AI/ML/data science  
**What you learn:** Python basics → NumPy/Pandas → scikit-learn → Deep Learning → GenAI + LLM APIs  
**Outcome:** Capable of AI engineer, ML engineer, or data scientist roles

### 3. DSA + Placement Preparation
**Who it's for:** Final-year students appearing for campus placements  
**What you learn:** Arrays → Linked Lists → Trees → Graphs → DP → Mock Interviews  
**Outcome:** Interview-ready for TCS NQT, Infosys, Wipro, Accenture, and competitive coding contests

### 4. C Programming Foundation
**Who it's for:** First-year BCA/B.Tech students + beginners  
**What you learn:** C syntax, pointers, memory management, data structures in C  
**Outcome:** Strong programming foundation for all future learning
